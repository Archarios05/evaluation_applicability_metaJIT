\subsection*{言語変化}
\label{differences}

この節は ``Revised$^4$ report''~\cite{R4RS} が出版されて以来 Scheme に
なされて来た変更点を列挙する。

\begin{itemize}

\item 本報告書は今や Scheme に対する IEEE 規格\cite{IEEEScheme}の
スーパーセットである:  本報告書に合致する実装はその規格にもまた合致する
ことになる。このことは下記の変更を要求した。
\begin{itemize}

\item 空リストは今や真とみなされることが要求される。

\item 機能が本質的 (essential) か非本質的 (inessential) かという分類は
なくなった。
今や組込み手続きの種類は原始的，ライブラリ，および省略可能の三種類である。
省略可能手続きは {\cf load}，
{\cf with-input-from-file}，{\cf with-output-\linebreak[0]to-file}，
{\cf transcript-\linebreak[0]on}，{\cf transcript-\linebreak[0]off}，
および {\cf interaction-\linebreak[0]environment}，
そして三引数以上の {\cf -} と {\cf /} である。
これらのどれも IEEE 規格にはない。

\item プログラムが組込み手続きを再定義してもよい。
そうすることによって他の組込み手続きの振舞が変わることはない。
\end{itemize}

\item {\em ポート}が，分離的な型のリストに加えられた。

\item マクロの付録はなくなった。
高水準マクロは今や報告書の本体の一部である。
派生式に対する書換え規則はマクロ定義で置き換えられた。
予約識別子は存在しない。

\item {\cf syntax-rules} は今やベクタ・パターンを許す。

\item 多重個の値の戻し (多値戻し，multiple-value return)，{\cf eval}，
および {\cf dynamic-wind} が加えられた。

\item 真正に末尾再帰的な方式で実装されることが要求される呼出しが，明示的に
定義された。

\item `{\cf @}' を識別子の中に使ってよい。
`{\cf \verb"|"}' は将来あり得る拡張のために予約された。

\end{itemize}
