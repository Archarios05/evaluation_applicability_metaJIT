# 計測結果

- 計測日時: 2026-10-22 21:40 / WSL2 Ubuntu (AMD Ryzen 7 7730U), `taskset -c 2` で 1 コアに固定
- 時間は各 10 回実行の最小値 (秒)。プロセス起動から終了までの壁時計時間
- バイナリは WSL のネイティブ FS (`~/metajit_bench`) にコピーして実行
- `error` は実装がエラーを出力して終了したもの (CPS 版 `sum` は C スタック溢れ)
